# 人狼シナリオメーカー

人狼動画のシナリオ（配役・議論の台本・投票・夜行動）を組み立てる個人用 PoC ツールです。
素の HTML / CSS / JavaScript のみで動作し、ビルド不要です。

## 使い方

`index.html` をブラウザで開くか、GitHub Pages で公開して利用します。

1. **① 配役**：登場人物の名前・色・役職・キャラ設定を入力
2. **② シナリオ**：日ごとに「昼の議論（台詞）→ 投票 → 処刑 → 夜行動」を入力
   - 生存者・投票集計・霊媒/占い結果・護衛成功・勝敗は自動計算
3. **③ 台本プレビュー**：テキスト台本として出力・コピー

データはブラウザの localStorage に自動保存されます。JSON で書き出し／読み込みも可能です。

## 対応役職

村人 / 人狼 / 占い師 / 霊媒師 / 騎士 / 狂人

## GitHub Pages での公開

リポジトリの Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `/ (root)` に設定します。
