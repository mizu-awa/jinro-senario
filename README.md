# 人狼シナリオメーカー

人狼動画のシナリオを手で組み立てる個人用 PoC。素の HTML / CSS / JavaScript、スマホ前提。

## 画面
- **配役**：メンバー（色・名前・役職）の編集、メンバーのプリセット保存/読込
- **シナリオ**：初日の夜 → 各日の「昼の台詞 → 投票 → 処刑 → 夜行動 → 夜の台詞」
- **台本**：テキスト台本の表示・コピー

データはブラウザの localStorage に自動保存。

## ルール（るる鯖準拠を想定）
- 役職：村人 / 人狼 / 占い師 / 霊能者 / 狩人 / 狂人 / 猫又 / 妖狐
- 初日犠牲者あり（人狼・妖狐・猫又以外から選択）、初日占いあり
- 占い・霊能結果は「人狼 / 人間」（妖狐・狂人・猫又は人間）
- 妖狐：襲撃では死なない、占われると呪殺。決着時に生存していれば妖狐の勝利
- 猫又：処刑されると生存者1人を、襲撃されると人狼1人を道連れ（対象は手動で選択）
- 狩人：自分以外を護衛
- 勝敗：人狼0で村人勝利、人狼 ≧ 人間で人狼勝利（妖狐生存なら妖狐勝利）
